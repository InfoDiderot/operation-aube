# Opération Aube — version Windows jouable

Téléchargement : [operation-aube-windows.zip](https://github.com/InfoDiderot/operation-aube/raw/builds/operation-aube-windows.zip)

1. Décompressez le zip (clic droit → **Extraire tout**).
2. Lancez `OperationAube.exe`.
3. Si SmartScreen bloque (exécutable non signé) : **Informations complémentaires** → **Exécuter quand même**.

Configuration : Windows 10/11 64 bits, carte graphique compatible Vulkan.
Sur un PC modeste, choisissez **Qualité graphique : Basse** dans le menu.

Cette branche ne contient que l'exécutable. Le code source est sur la branche `main`.
